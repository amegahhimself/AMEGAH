# Amegah.com

Portfolio website for Amegah (director, cinematographer & photographer).
Built with Next.js 16 and Sanity CMS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the site, or
[http://localhost:3000/studio](http://localhost:3000/studio) for the Sanity
Studio.

## Tests

```bash
npm test
```
